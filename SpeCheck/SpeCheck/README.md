# SpeCheck

SpeCheck is a local Windows quick-check tool for reviewing a laptop, including a used gaming laptop, before purchase. It reads hardware details through Windows PowerShell and Windows system reports. It does not upload data or require an account.

## Run it

1. Install Python 3 for Windows from [python.org](https://www.python.org/downloads/windows/). Keep **Add python.exe to PATH** enabled.
2. Extract the `SpeCheck` folder from the ZIP.
3. Double-click `Run-SpeCheck.bat`.
4. Run **Quick check** for a one-time scan. It does not keep polling in the background.

SpeCheck uses Python's built-in Tkinter and Windows PowerShell. It has no `pip install` dependencies.

## Features

- **Quick check:** displays battery health and cycle count when reported, memory use and module summary, and storage free/total with drive type/model/health; processor model/core/thread/maximum-clock specifications; graphics adapter identification; plus matching critical/error entries from selected hardware-related Windows event providers in the last 14 days.
- **Gaming laptop focus:** when Windows lists an NVIDIA adapter, SpeCheck highlights it ahead of integrated graphics so the model is easier to spot.
- The banner flags battery wear, low drive space, Windows drive warnings, and selected recent system errors. These are clues to review, not a certification or an overall score.
- Storage capacity comes from each local Windows volume, while drive health comes from the Windows Storage Management provider. These are separate readings, so the app can show free space even when a drive does not report a health status.
- **Components:** a component table with physical drive model/type/health and RAM module size/manufacturer/part number/configured speed when Windows reports them, plus a button to open Windows Memory Diagnostic. Windows may ask to restart before testing memory; SpeCheck does not restart the computer.
- **Check details:** explains what was measured and lists quick physical checks to do before buying.
- **Reliability Monitor:** a button opens Windows Reliability Monitor for a fuller view of logged app and system failures.
- **Export report:** save the latest local scan as a JSON file.
- **Open Windows battery report:** create and open the report generated by `powercfg`.

## How battery health is calculated

SpeCheck calculates:

`Full Charge Capacity ÷ Design Capacity × 100`

It first checks Windows battery capacity interfaces and falls back to parsing the local `powercfg /batteryreport` HTML report. For the values in the supplied report (33,911 mWh full-charge capacity and 58,003 mWh design capacity), the displayed estimate is **58.5%**.

## Readings and limits

- Processor readings are identification and Windows-reported core, thread, and maximum-clock specifications. SpeCheck does not show processor temperature or live usage, and it does not run a benchmark or stress test.
- Memory readings include installed capacity/current usage and per-module details when Windows supplies them. Configured speed is preferred over rated speed. Use Windows Memory Diagnostic to test memory; this app does not label memory healthy based on usage.
- Battery cycle count comes from the Windows battery interface when the laptop exposes it. A zero or missing value is shown as “Not reported,” not as a verified new battery.
- Device banners use a matching local manufacturer wordmark for common PC brands; unknown manufacturers use a neutral fallback.
- Graphics readings identify adapters. The Windows-reported adapter-memory field can cap at about 4 GB, so verify the exact GPU and VRAM from its model specification. No GPU benchmark is run.
- Drive health uses the Windows Storage Management provider when available. Some drives do not expose a health value.
- System-event entries can have different causes and do not prove a component is failing. SpeCheck counts selected System log errors from the last 14 days; inspect the event details before drawing a conclusion.
- This quick check cannot test a screen, keyboard, ports, hinges, charger, Wi-Fi, speakers, GPU performance, or RAM integrity. Inspect these in person and run a game or benchmark when possible.
- If the battery percentage is unavailable, open the Windows battery report from the Check details page. If the report itself lacks either capacity, Windows is not exposing enough information for SpeCheck to calculate it.

## Tests

From this folder, run `python -m unittest discover -s tests -v`. The checks verify battery parsing, quick-check flags and coverage, GPU selection, memory units, and storage calculations.
